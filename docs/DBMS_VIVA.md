# DBMS Viva Demonstration

1. Show `users` and role separation.
2. Show 1:1 user-to-student/recruiter relationships.
3. Show many-to-many `job_skills` and `student_skills`/`seeker_skills`.
4. Upload a resume and show a `resumes` row.
5. Analyze it and show `resume_analysis` + `resume_suggestions` rows.
6. Create a job and show `jobs` + `job_skills`.
7. Run job matching and show `job_matches`.
8. Apply and show `applications`.
9. Change application status and create a notification.
10. Open candidate resume and insert `resume_views`.
11. Run the queries in `database/queries.sql` to demonstrate JOIN, GROUP BY, HAVING, aggregates, filtering and ranking.
12. Explain indexes on role, job status/title/description, resume text, notifications and resume score.
